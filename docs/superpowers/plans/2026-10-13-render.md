# Render Stage Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** From an ingested run, produce a Markdown tree for LLMs and a PDF book per course, automatically after ingest and on demand.

**Architecture:** New package `canvas_sync.render`. `tree.py` orders items from the snapshot (modules first). `htmlmd.py` converts exported HTML to Markdown with the stdlib parser. `pdftools.py` wraps poppler, Chromium and pypdf behind feature detection. `md_out.py` writes the tree, index and `_full.md`. `book.py` renders print HTML, prints with Chromium, splices lecture PDFs with pypdf and adds an outline. `render_run` is called from `ingest._after_commit` and from the CLI.

**Tech Stack:** Python 3.11+ stdlib; optional runtime tools: `pdftotext`, `pdftoppm` (poppler), `chromium-browser`/`chromium`/`google-chrome` headless, `pypdf`. unittest.

**Spec:** `docs/superpowers/specs/2026-10-13-render-design.md`

## Global Constraints

- No new required dependencies. Optional tools feature-detected in `pdftools.py`; absence degrades a feature with one log line, never raises out of `render_run`.
- Markdown output never contains raw HTML tags except as a single-line note for unsupported constructs.
- All links inside the Markdown tree are relative and resolve to files that exist in the tree.
- Output roots: `md/<course_dir>/<stamp>_run<id>/`, `books/<course_dir>/<stamp>_run<id>.pdf`, each with a `latest` pointer.
- Rendering a run twice yields byte-identical Markdown (no timestamps other than the run's export date).
- Tests: `cd sync && python -m unittest discover -s tests -v`. Tool-dependent tests skip when the tool is absent.

## Review Focus

1. **Quiz HTML with `(correct)`/`(incorrect)` em markers and selected styles** must become `✅`/`❌`/`▶` prefixes, never dropped. Test in Task 2 (`test_quiz_marks`).
2. **A page item referenced from a module by slug** must resolve to the page keyed by `page_id` via `meta.slug`; otherwise pages fall out of module order silently. Test in Task 1 (`test_module_page_by_slug`).
3. **Non-rectangular tables** (colspan, missing cells) must not produce a broken pipe table; fall back to a list. Test in Task 2 (`test_ragged_table_falls_back`).
4. **Missing poppler** must still produce the `.pdf.md` stub and copy the PDF, and the book must still build without splicing when pypdf is missing. Tests in Task 4 (`test_pdf_text_without_poppler`) and Task 6 (`test_book_without_pypdf`).
5. **Filenames with `#`, `%` or spaces** must be URL-encoded in Markdown links so viewers and LLM tooling resolve them. Test in Task 5 (`test_links_are_url_encoded`).

### Task 1: Item tree (`tree.py`)

**Files:** Create `sync/canvas_sync/render/__init__.py` (empty for now), `sync/canvas_sync/render/tree.py`, `sync/tests/test_render_tree.py`

**Interfaces:**
- `@dataclass Node(item: dict, children: list[Node], kind: str)` where `kind` ∈ `module | item | group`.
- `build_tree(snapshot: dict) -> list[Node]`: modules in `meta.position` order, each with children resolved from `meta.items` (`Assignment`→assignment by `contentId`, `Quiz`→quiz, `File`→file, `Page`→page via `meta.slug == contentId`, `Discussion`→discussion); unresolved module items become `kind="item"` nodes with `item={"type": "external", "title": ..., "meta": {...}}`. Then one `group` node per remaining type in order `assignment, quiz, announcement, discussion, page, file, submission, synthetic` containing items not placed in any module. Synthetic `styles.css` and `_inaccessible_links.csv` excluded.
- `flatten(nodes) -> list[dict]` items in reading order.

- [ ] Write tests: module order, page-by-slug, unreferenced grouping, external item, excludes styles.css.
- [ ] Run, see failures. Implement. Run green. Commit `feat(render): ordered item tree from snapshot`.

### Task 2: HTML to Markdown (`htmlmd.py`)

**Files:** Create `sync/canvas_sync/render/htmlmd.py`, `sync/tests/test_htmlmd.py`

**Interfaces:**
- `html_to_markdown(html: str, link_map: Callable[[str], str | None] = None, image_map: Callable[[str], str | None] = None) -> str`. `link_map(href)` returns the replacement target or None to keep; `image_map(src)` likewise. Strips the export wrapper (`<h1>` title and stylesheet link) when present.
- Handles: h1–h6 (h1 demoted to h2 inside body), p, br, div, ul/ol nested, li, blockquote, pre/code, strong/b, em/i, a, img, hr, table (rectangular → pipe table; ragged → list of rows joined by ` | `), iframe/video/audio → `[Video: title](src)` line, script/style/noscript/head dropped, entities decoded, whitespace normalised, `&nbsp;` → space.
- Quiz marks: `<em>(correct)</em>` → leading `✅ `, `<em>(incorrect)</em>` → `❌ `, list items with `style` containing `font-weight:600` and no mark → `▶ ` (selected), `✓ `/`✗ `/`• `/`◇ ` prefixes from the scraper map to `✅ `/`❌ `/`▶ `/`✔ ` respectively.

- [ ] Write tests: headings, nested lists, table ok, ragged table, code, links via map, images via map, quiz marks, junk removal, wrapper stripping, entities.
- [ ] Run red. Implement with `html.parser.HTMLParser` building a small node tree then emitting. Run green. Commit `feat(render): stdlib HTML to Markdown converter`.

### Task 3: Tool detection and wrappers (`pdftools.py`)

**Files:** Create `sync/canvas_sync/render/pdftools.py`, `sync/tests/test_pdftools.py`

**Interfaces:**
- `find_tool(name) -> str | None` (PATH lookup; `chromium` tries `chromium-browser`, `chromium`, `google-chrome`, `google-chrome-stable`).
- `have_pypdf() -> bool`.
- `pdf_page_count(path) -> int | None` (pypdf, else `pdfinfo`, else None).
- `pdf_text_pages(path) -> list[str] | None` via `pdftotext -layout`, split on form feed; None if tool missing.
- `pdf_page_png(path, page: int, out_png: Path, dpi=110) -> bool` via `pdftoppm -f N -l N -png -r dpi -singlefile`.
- `html_to_pdf(html_path, out_pdf) -> bool` via Chromium headless `--headless=new --disable-gpu --no-pdf-header-footer --print-to-pdf=<out> file://...`; returns False if no binary or non-zero exit.
- `Capabilities` dataclass + `detect() -> Capabilities` with fields `pdftotext, pdftoppm, pdfinfo, chromium, pypdf` (paths or bool).

- [ ] Tests: `find_tool` on a fake PATH dir with executables; `pdf_text_pages` returns None when tool missing (monkeypatch); integration test for text pages and page png on a tiny PDF generated in the test with pypdf (skip if pypdf or poppler missing); `html_to_pdf` integration skip if no chromium.
- [ ] Commit `feat(render): optional tool detection and PDF wrappers`.

**Interfaces:**

### Task 5: Markdown tree, index, `_full.md` (`md_out.py` part 2)

**Files:** Modify `sync/canvas_sync/render/md_out.py`; Modify `sync/tests/test_md_out.py`

**Interfaces:**
- `render_markdown(store, run_id, caps, all_pages=False) -> Path` (the run's md dir). Steps: load snapshot; build tree; compute `md_path(item)` for every item with a path (`.html`→`.md`, `.csv` Grades → `Grades.md`, pdf → `.pdf.md`, other files → copied as-is, link to file); build `link_map` from export-relative hrefs (resolve against the item's own folder) to md-relative targets with URL-encoding; convert each doc item with frontmatter; copy images referenced to `images/<sha12>.<ext>` and map `<img src>`; write `Grades.md` table; write `index.md`; write `_full.md`; create/refresh `latest` symlink.
- Frontmatter keys: type, canvas_id, title, source (built from domain + type pattern as in `changes`/urlMap: assignments `/assignments/<id>`, quizzes `/quizzes/<id>`, pages `/pages/<slug>`, announcements & discussions `/discussion_topics/<id>`, files `/files/<id>`), run, exported_at, plus every meta key that is not null and not `items`.

- [ ] Tests on a synthetic run (helpers from `tests/helpers.py`): files exist with `.md`; frontmatter has `type` and `canvas_id`; link in assignment body to another assignment becomes relative `.md` link; image copied under `images/` and referenced; `index.md` lists module children in order; `_full.md` contains each item once in index order; filenames with `#` and spaces encoded in links; rendering twice is byte-identical; `latest` symlink exists.
- [ ] Commit `feat(render): Markdown tree, index and _full.md`.

### Task 6: PDF book (`book.py`)

**Files:** Create `sync/canvas_sync/render/book.py`, `sync/tests/test_book.py`

**Interfaces:**
- `render_book(store, run_id, caps, md_dir: Path) -> Path | None`. Builds `book.html` in a temp dir from the Markdown files (own minimal Markdown-to-HTML for the subset we emit: headings, paragraphs, lists, tables, code, links, images, hr, bold/italic), with print CSS, cover and TOC placeholders; `html_to_pdf`; if pypdf: open the printed PDF, find each item's start page by reading the `<!-- part: N -->` marker printed as hidden text (we print each part starting with a page-break and a tiny white marker line `PART:<n>`; pypdf text extraction finds it), then assemble: cover, TOC page(s) (rendered separately after page numbers are known, second Chromium pass of a tiny HTML), parts in order, inserting original PDF pages after a file part's heading page; add outline; write to `books/<course_dir>/<stamp>_run<id>.pdf` and `latest.pdf` symlink. If no pypdf: write the printed PDF as-is. If no chromium: return None.

- [ ] Tests: Markdown-to-HTML subset unit tests; `test_book_without_chromium` returns None; `test_book_without_pypdf` writes the printed file when `html_to_pdf` is monkeypatched to copy a fixture PDF; integration (skip unless chromium+pypdf+poppler): synthetic run with one real tiny PDF → book has outline entries for module and items, page count = printed pages + spliced pages.
- [ ] Commit `feat(render): PDF book with spliced lecture PDFs and outline`.
